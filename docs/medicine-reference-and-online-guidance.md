# Medicine reference and optional internet lookup

The local PNF EML 2022 list contains 659 supplied rows, not prescribing information. Add and edit medicine forms offer prefix and conservative typo suggestions. Tap to choose a suggestion; names, strengths, instructions and schedules are never automatically changed. Check the prescription/packaging, especially similar names, salts and combinations. See the reference README for the corrected CSV column interpretation.

The assistant has two additional tools: `lookup_medicine_reference` (local, immediate) and `search_medicine_guidance` (internet, confirmation required). The controller requires a successful local lookup for the same name during the current user turn before offering online permission. The model should clarify uncertain names before searching. The local catalog's presence does not mean safety instructions are available.

Each online proposal displays the exact name and topic and requires a new approval. Cancel/Stop invalidates the review. Approval is consumed once and cannot be reused. NHS receives the IP address and requested pages, but no chat, records, doses, symptoms, location or authorization credentials. The provider is currently NHS Medicines A–Z, not a general search engine or cloud model. Its index is searched for one exact medicine title (parenthetical brand labels are accepted). Ambiguous formulations, absent medicines, HTTP failures, redirects and offline/timeout errors fail explicitly; there are no fuzzy online substitutions or automatic retries.

The lookup reads the matched page and, when linked, its how-and-when page. It returns a source URL and a complete, bounded missed-dose/food section only if there is a matching heading and no dose-unit text. Otherwise it returns a link without claiming to retrieve clinical instructions. Never truncate clinical caveats. Food information may have no matching section. General safety returns a source link. Sources may differ from Philippine product labeling; verify the exact leaflet or consult a pharmacist. This is not prescribing, personalized catch-up advice or proof a medication is suitable. Model wording still needs real-device evaluation; prompt instructions are not a medical safety guarantee.

After an online result, the controller disables further tools for that turn, so external content cannot trigger database writes or scheduling. The existing five-completion/context limits apply. No database schema changes, migrations, seeds, persistent chat, internet-consent storage or native dependencies were added.
